## Executive Summary

**Gmail Signature Manager** overcomes Gmail's native signature limitations by providing a multi-account, domain-matched HTML signature switcher. Users can create, store, and automatically swap rich HTML signatures based on recipient email domain, sender alias, or business persona.

- **Capabilities**: Unlimited HTML signature templates, recipient domain matching rules, logo hosting, and live signature preview.
- **Integration**: Injects directly into Gmail's iframe message composer without disturbing draft text or recipient lists.

---

## Technical Solutions & Execution

### 1. Dynamic Compose Body Injection
Monitors Gmail DOM compose windows using dynamic mutation listeners. When a user changes the "From" address or types a recipient in the "To" field, the extension evaluates matching rule predicates and injects the corresponding HTML signature template into the message container.

### 2. Rich HTML & CSS Sanitization
Ensures custom signatures maintain cross-client email rendering standards (Outlook, Gmail mobile, Apple Mail) by stripping non-standard CSS properties and embedding clean inline style attributes.

### 3. Chrome Sync Storage Synchronization
Persists signature templates and rule matrices using `chrome.storage.sync`, enabling seamless setup across all user browser instances.
