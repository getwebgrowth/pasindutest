## Executive Summary

**Bonk Terminal** is a full-stack Web3 trading intelligence application built for the Solana ecosystem. Featuring a terminal-style CLI dashboard, the platform streams sub-second token transaction metrics, price candlestick charts, DEX liquidity changes (Raydium, Orca), and AI price trend predictions.

- **Live Platform**: [bonk-terminal.vercel.app](https://bonk-terminal.vercel.app)
- **Key Features**: High-frequency RPC WebSocket streams, clipboard auto-paste, BLYV token analyzer, and Solana Tracker API integration.

---

## Technical Stack & Architecture

### 1. Terminal UI Componentry
Custom command-line user interface built with React, Tailwind CSS, and Framer Motion, supporting keyboard shortcuts (`Command+K`), command history, and instant token search.

### 2. Solana Web3 & RPC Stream Pipeline
Connects to high-throughput Solana RPC nodes over WebSocket subscriptions (`accountSubscribe`, `logsSubscribe`) to display token swaps, mint events, and pool liquidity changes instantly.

### 3. AI Token Trend Scoring
Applies momentum indicators (RSI, volume spikes, wallet concentration metrics) to rank trending Solana tokens in real time.
