## Executive Summary

**Auto Suggest** is a high-performance browser extension that turns any input field, textarea, or rich text editor on the web into a smart, AI-powered writing surface. Powered by OpenAI's streaming API, the extension analyzes surrounding DOM context and user typing history to offer instant inline autocomplete suggestions with zero latency lag.

- **Use Cases**: Email drafting, content creation, customer support responses, and social media posting.
- **Key Capability**: Contextual awareness that reads active page headers and surrounding text to generate relevant completions.
- **Latency**: Under 150ms time-to-first-token using Server-Sent Events (SSE).

### 1. Cross-Site Contenteditable & Textarea Hooking
Standard inputs and iframe-based WYSIWYG editors (Draft.js, Quill, TinyMCE, Gmail composer) handle text selection differently. I engineered a universal DOM listener using the Selection & Range API to capture caret positioning without breaking native editor state.

### 2. Low-Latency SSE Token Streaming
Rather than waiting for complete API payloads, the service worker listens to streamed Server-Sent Events from OpenAI, rendering "ghost text" inline in real-time as the user types.

### 3. Ghost Text Inline Rendering
Suggestions are presented using an unobtrusive inline overlay. Pressing `Tab` or `Right Arrow` commits the suggestion into the target element without disturbing undo/redo history.
