## Executive Summary

**Walmart Product Scraper** is a high-volume e-commerce automation tool that eliminates manual catalog ingestion for multi-channel marketplace sellers. It pairs a **Manifest V3 Chrome Extension** for robust client-side scraping (bypassing strict PerimeterX / Akamai anti-bot defenses) with a **Google Apps Script backend** powered by **OpenAI GPT-4o Vision** for automated image OCR and listing optimization.

- **Source Code**: [github.com/pasindupiumal03/Walmart-Product-Scrapes-Extension](https://github.com/pasindupiumal03/Walmart-Product-Scrapes-Extension)

---

## Key Features

1. **Client-Side Anti-Bot Bypass**: Executes within a real browser session to bypass Akamai Bot Manager and CAPTCHA walls that block traditional cloud scraping proxies.
2. **Deep JSON Data Extraction**: Intercepts internal next.js/hydration data payloads to extract high-resolution product images, variants, seller info, and inventory levels.
3. **GPT-4o Vision AI Enrichment**: Automatically processes product packaging images to extract ingredient lists, certification badges, and compliance warnings.
4. **Google Sheets Sync**: Streams validated product data directly into shared client Google Sheets with zero duplicate entries.

---

## Technical Stack

- **Extension**: Manifest V3, Chrome Offscreen API, MutationObserver.
- **AI & Processing**: OpenAI API (GPT-4o Vision & GPT-4o-mini).
- **Backend & Storage**: Google Apps Script, Google Sheets API, Google Drive API.
