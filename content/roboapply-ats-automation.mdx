## The Challenge

Automating job application portals is widely recognized as one of the hardest browser automation problems due to ATS architecture diversity:

1. **Ashby's Dynamic Canvas & Virtualized Inputs**: Ashby uses heavily virtualized DOM nodes with proprietary synthetic event listeners that ignore standard `.value = ...` JavaScript assignments. Over 20 prior developers failed because basic DOM selectors could not trigger form state validation.
2. **Workday's Multi-Page Nested Wizard**: Workday splits applications across 5 to 10 paginated steps with session-locked CSRF headers, dynamic dropdown search triggers, and strict file upload validation.
3. **Greenhouse & Lever Dynamic Questionnaires**: Companies insert custom, open-ended screening questions (e.g. "Describe your experience with distributed systems") that require real-time contextual AI answers based on the user's uploaded master resume.
4. **CAPTCHA & Human-Check Pause Points**: The extension must pause gracefully when Cloudflare or hCaptcha challenges arise and resume immediately upon human completion without losing progress.

### 1. Synthetic Event Simulation (Cracking Ashby ATS)
Standard DOM manipulation fails on modern React frameworks because state updates require internal React fiber synthetic events (`input`, `change`, `blur`, `focus`, `keydown`). I implemented a low-level event synthesizer that triggers native event dispatchers in the target page's execution world, successfully updating Ashby's internal validation state.

### 2. Multi-Step MutationObserver Navigation (Workday Automation)
Built a recursive state machine that:
- Detects the current Workday wizard stage (Contact Info, Experience, Education, Voluntary Disclosures).
- Auto-populates complex nested select menus by simulating keyboard search queries and waiting for dynamic AJAX result sets.
- Injects binary PDF resume files directly into file dropzones using native `DataTransfer` and `FileList` constructor bridges.

### 3. Contextual AI Resume & Answer Generator
Connected OpenAI GPT-4o to match open-ended screening questions against candidate work experience:
- Summarizes relevant past job history to answer questions like *"Why are you interested in this role?"* with customized, highly relevant responses.
- Generates matching answers in under 1.5 seconds directly within the active extension workflow.
