## Executive Summary

**Easy Input** is a comprehensive learning and productivity Chrome extension designed for language learners, researchers, and students. By selecting any text across the web, users open an floating toolbar to save phrases, look up contextual translations, hear native audio pronunciations, generate spaced-repetition flashcards, and sync items to their dashboard.

- **Capabilities**: Text selection capture, multi-language translation, Web Speech audio, Anki CSV export, and cloud synchronization.
- **UI Architecture**: Glassmorphic floating popover rendered inside isolated Shadow DOM.

---

## Technical Stack & Architecture

### 1. Selection Toolbar Component
Listens to `mouseup` and `selectionchange` events across arbitrary web pages. Calculates precise bounding rectangles (`getBoundingClientRect`) to float the action menu above selected text without flickering.

### 2. Native Web Speech & Translation Engine
Connects directly to Web Speech API synthesis for instant audio playback without external latency, backed by cloud translation APIs for multi-language context matching.

### 3. Offline-First IndexedDB Sync
Uses local IndexedDB storage to record saved phrases offline, automatically syncing state with the user's web account when connection is restored.
