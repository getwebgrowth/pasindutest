## Executive Summary

**Censor AI** is a productivity Chrome extension that seamlessly integrates OpenAI language models into the Gmail web interface. Users type natural rough drafts, and Censor AI suggests professionally formatted, grammatically polished, and tone-adjusted variations (Formal, Friendly, Direct, Persuasive) with one-click injection back into the Gmail compose body.

- **Status**: Live on the [Chrome Web Store](https://chromewebstore.google.com/detail/censor/elgfhammpjfmmgiflpjbohhbimlfdimm)
- **Specialty**: Non-destructive Gmail compose window DOM injection and real-time streaming LLM completions.

## Engineering Architecture & System Design

```
┌─────────────────────────────────────────────────────────────┐
│                    Gmail Browser Tab (MV3)                  │
│                                                             │
│  ┌─────────────────────────────┐   ┌─────────────────────┐  │
│  │ Gmail DOM Mutation Listener │   │ Custom Floating HUD │  │
│  │ (Active Compose Iframe)     │──►│ (Tone Selector UI)  │  │
│  └──────────────┬──────────────┘   └──────────▲──────────┘  │
│                 │ Extracted Draft Text        │ Transformed  │
│                 ▼                             │ Draft Insert │
│  ┌────────────────────────────────────────────┴──────────┐  │
│  │ Background Service Worker & OpenAI Stream Listener    │  │
│  └──────────────────────────────┬────────────────────────┘  │
└─────────────────────────────────┼───────────────────────────┘
                                  ▼
                        OpenAI GPT-4o API
```

### 1. Gmail Dynamic Compose Window Injector
Gmail dynamically generates compose windows with nested contenteditable divs. Censor AI uses a robust `MutationObserver` pipeline to detect new compose frames, attaching an unobtrusive AI floating toolbar without overriding native email state.

### 2. Multi-Tone Prompt Pipeline
Structures the user's raw draft text into context-aware OpenAI prompts, returning formatted HTML body replacements that preserve email line breaks and salutations.
