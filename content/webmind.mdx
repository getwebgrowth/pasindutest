## Executive Summary

**WebMind** (also known as Tandem) is a personal AI memory assistant that index-scans visited web content and stores vector embeddings locally. Instead of manually searching through bookmarks or browser history, users can ask natural language questions (e.g. *"What was that article I read about Solana NFT RPC nodes?"*) and get instant semantic search results with exact text highlights.

- **Privacy Guarantee**: All page content is encrypted locally using AES-GCM before storage in `IndexedDB`.
- **Target Users**: Researchers, developers, traders, and students requiring instant recall of complex technical materials.

## Technical Stack & Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                    Chrome Browser (MV3)                     │
│                                                             │
│  ┌─────────────────────────────┐   ┌─────────────────────┐  │
│  │ Page Content Extractor      │   │ SidePanel Chat HUD  │  │
│  │ (Background Service Worker) │──►│ (Natural Language)  │  │
│  └──────────────┬──────────────┘   └──────────▲──────────┘  │
│                 │ Vector Chunk Embeddings     │ Grounded    │
│                 ▼                             │ Query Result│
│  ┌────────────────────────────────────────────┴──────────┐  │
│  │ IndexedDB Encrypted Local Vector Database             │  │
│  └──────────────────────────────┬────────────────────────┘  │
└─────────────────────────────────┼───────────────────────────┘
                                  ▼
                     OpenAI Embeddings API
```

### 1. Vector Embeddings Indexer
Extracts page body text in background worker threads, generating text chunk embeddings via OpenAI's `text-embedding-3-small` API. Stores vector embeddings in IndexedDB for instant cosine similarity queries.

### 2. Sidepanel Natural Language Query Interface
Built using React, Tailwind CSS, and Chrome's native SidePanel API, providing a clean chat interface that answers questions grounded directly in the user's personal web history context.
