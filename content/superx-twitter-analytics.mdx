## Executive Summary

**SuperX** is an enterprise social media intelligence suite combining a Manifest V3 Chrome extension with a dedicated web dashboard. Engineered for content creators, founders, and marketing teams, SuperX injects real-time engagement metrics, viral post predictors, and audience growth charts directly into Twitter/X timelines.

- **Chrome Web Store**: [Chrome Web Store Listing](https://chromewebstore.google.com/detail/superx-twitter-analytics/bjobgelaoehgbnklgcaaehdpckmhkplk)
- **Architecture**: Chrome Extension (Frontend Injector) + Node.js/Express Backend + Analytics Pipeline.

## Engineering Architecture & System Design

```
┌─────────────────────────────────────────────────────────────┐
│                    Twitter/X Browser Tab (MV3)              │
│                                                             │
│  ┌─────────────────────────────┐   ┌─────────────────────┐  │
│  │ X Timeline DOM Interceptor  │   │ Analytics Overlay   │  │
│  │ (GraphQL API Listener)      │──►│ (Viral Hook HUD)    │  │
│  └──────────────┬──────────────┘   └──────────▲──────────┘  │
│                 │ Intercepted Post Metrics    │ Sync Analytics│
│                 ▼                             │ Response     │
│  ┌────────────────────────────────────────────┴──────────┐  │
│  │ Node.js / Express SaaS Backend + Redis Cache          │  │
│  └──────────────┬─────────────────────────────┬──────────┘  │
└─────────────────┼─────────────────────────────┼─────────────┘
                  ▼                             ▼
         PostgreSQL Database           Stripe Billing API
```

### 1. GraphQL Network Interception Layer
Intercepts Twitter/X's internal GraphQL HTTP requests in real-time, capturing engagement counters, impression numbers, and quote retweet metadata without polling DOM elements.

### 2. Timeline Analytics HUD
Renders a custom React overlay over tweets, displaying calculated engagement rates, impression velocity, and viral hook scores directly inside the Twitter UI.
