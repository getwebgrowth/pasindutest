## Executive Summary

**Solana Tracker** is a real-time Web3 portfolio tracking application designed for Solana traders and DeFi investors. It connects seamlessly to Phantom and Solflare wallets, querying on-chain token balances, dynamic SPL token prices, PnL calculations, and historical transaction graphs with sub-second RPC updates.

- **Live URL**: [solan-nine.vercel.app](https://solan-nine.vercel.app/)
- **GitHub Repository**: [github.com/pasindupiumal03/Solana_User_Dashboard](https://github.com/pasindupiumal03/Solana_User_Dashboard)

---

## Technical Stack & Architecture

### 1. RPC Connection Failover & Batching
Uses `@solana/web3.js` connected to Helius and QuickNode RPC clusters, implementing exponential retry backoff and batch token account queries (`getParsedTokenAccountsByOwner`) to ensure 99.9% data availability during high network congestion.

### 2. Glassmorphic Responsive Dashboard
Built with Next.js App Router, TypeScript, Tailwind CSS, and shadcn/ui. Provides interactive price performance charts, token balances, and wallet activity streams.
