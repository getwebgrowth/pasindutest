## Executive Summary

**Solana Tracker** is a real-time Web3 portfolio tracking application designed for Solana traders and DeFi investors. It connects seamlessly to Phantom and Solflare wallets, querying on-chain token balances, dynamic SPL token prices, and historical transaction graphs with sub-second RPC updates.

- **Live URL**: [solan-nine.vercel.app](https://solan-nine.vercel.app/)
- **Source Code**: [github.com/pasindupiumal03/Solana_User_Dashboard](https://github.com/pasindupiumal03/Solana_User_Dashboard)

---

## Technical Stack & Architecture

- **Frontend**: Next.js (App Router), TypeScript, shadcn/ui, Tailwind CSS.
- **Web3 Layer**: Solana Web3.js, SPL Token Registry, QuickNode / Helius RPC clusters.
