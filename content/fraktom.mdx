## Executive Summary

**Fraktom** is a gamified crypto trading simulation platform that allows traders to experiment with high-volatility token dynamics in a risk-free environment. Inspired by bonding curve token launchers like pump.fun, Fraktom features dynamic mathematical price curves, mock liquidity pools, real-time portfolio performance tracking, and competitive trader leaderboards.

- **Live URL**: [fraktom.vercel.app](https://fraktom.vercel.app/)
- **GitHub Repository**: [github.com/pasindupiumal03/Fraktom_Homepage](https://github.com/pasindupiumal03/Fraktom_Homepage)

## Technical Stack & Architecture

### 1. Mathematical Bonding Curve Engine
Implements automated market maker (AMM) bonding curve formulas ($y = k \cdot x^2$) to calculate real-time token pricing based on simulated supply and demand.

### 2. High-Frequency State Synchronization
Built using Next.js, React 19, and Tailwind CSS with optimistic UI updates to simulate instant execution and live price updates without server latency.
