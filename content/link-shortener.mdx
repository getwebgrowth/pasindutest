## Executive Summary

**Link Shortener** is a modern browser utility extension designed for marketers, content creators, and professionals. With a single click or keyboard shortcut, the extension minifies the active tab URL, copies the short link directly to clipboard, generates a high-resolution vector QR code for mobile scanning, and logs history metrics locally.

- **Capabilities**: 1-click active URL shortening, QR code download (PNG/SVG), link history search, and Bitly / dub.co API integration.

---

## Technical Features & Stack

### 1. Offline Vector QR Code Engine
Generates high-resolution SVG and PNG QR codes in client-side memory using pure JavaScript, allowing users to project or download codes offline without external tracking servers.

### 2. Active Tab URL Interception
Uses `chrome.tabs.query` to capture the current active URL securely without requesting broad web permission scopes, preserving browser privacy and security standards.
