## Executive Summary

**Amazon Product Scraper** is a specialized e-commerce automation tool designed for Amazon sellers, brand managers, and product researchers. Given a list of ASINs or product URLs, the tool extracts titles, bullet points, descriptions, price history, brand metrics, and applies Optical Character Recognition (OCR) to extract text buried inside main product images.

- **Source Code**: [github.com/pasindupiumal03/Amazon-Product-Scrapes-Extension](https://github.com/pasindupiumal03/Amazon-Product-Scrapes-Extension)
- **Key Capability**: Hybrid extraction combining client-side DOM scraping (bypassing CAPTCHAs) with OCR image parsing and direct Google Sheets appending.

---

## Technical Features & Solutions

### 1. Client-Side Scraping (Bot-Detection Bypass)
By executing data extraction in client-side browser contexts using background extension content scripts, the scraper bypasses cloud WAF gateways and IP bans that block traditional server-side Puppeteer scripts.

### 2. OCR Image Infographic Extraction
Uses Tesseract OCR and Vision API bridges to read text embedded inside product infographics (nutrition facts, dimension labels, warranty details), ensuring 100% data capture.

### 3. Direct Google Sheets Sync
Pushes normalized listing rows directly into user Google Sheets using OAuth2 tokens and Google Apps Script Webhooks.
