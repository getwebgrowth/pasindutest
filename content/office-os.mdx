## Executive Summary

**Office OS** is a workflow workspace application built directly on top of Google Workspace using Google Apps Script. It turns a standard Google Spreadsheet into an interactive drag-and-drop Kanban task board, client pipeline manager, and Pomodoro focus timer with zero external hosting fees.

- **Storage**: 100% private data persistence inside user Google Drive.
- **Performance**: Optimistic UI DOM state updates with batch Apps Script sync.

---

## Technical Features & Solutions

### 1. Drag-and-Drop Kanban Component
Built using HTML5 Drag and Drop API inside Apps Script `HtmlService`, allowing users to move task cards between columns (To Do, In Progress, Review, Completed) with automatic sheet row updates.

### 2. Built-In Pomodoro Focus Timer
Embedded audio-visual countdown timer with customizable session lengths, logging focus time directly against specific project tasks in the database.
