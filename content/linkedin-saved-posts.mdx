## Executive Summary

**OneLearning** (LinkedIn Saved Posts Manager) turns LinkedIn's basic bookmarking feature into a fully organized, searchable knowledge management workspace. Users import saved items with a single click, categorize posts using custom color-coded tags (Startup, Marketing, Finance, Education, Health), attach personal study notes, and export insights to Markdown or Notion.

- **Problem Solved**: LinkedIn buries saved posts deep inside user profile menus without search, tagging, or export capabilities.
- **Key Features**: 1-click import, custom tag taxonomy manager, instant search filtering, and offline IndexedDB persistence.

## Engineering Architecture & System Design

```
┌─────────────────────────────────────────────────────────────┐
│                   LinkedIn Browser Tab (MV3)                │
│                                                             │
│  ┌─────────────────────────────┐   ┌─────────────────────┐  │
│  │ Saved Posts DOM Parser      │   │ Sidepanel React UI  │  │
│  │ (linkedin.com/my-items/)    │──►│ (Filter & Tag HUD)  │  │
│  └──────────────┬──────────────┘   └──────────▲──────────┘  │
│                 │ Parsed Post Cards           │ Instant Search│
│                 ▼                             │ Query Results │
│  ┌────────────────────────────────────────────┴──────────┐  │
│  │ IndexedDB Local Vector & Tag Taxonomy Store           │  │
│  └──────────────────────────────┬────────────────────────┘  │
└─────────────────────────────────┼───────────────────────────┘
                                  ▼
                   Notion & Markdown Export Bridge
```

### 1. Resilient LinkedIn DOM Parser
Injects content scripts to parse saved posts (`linkedin.com/my-items/saved-posts/`), extracting post copy, media attachments, author profiles, and timestamps cleanly without breaking when LinkedIn updates CSS layout classes.

### 2. Sidepanel UI Componentry
Built using React 18 and Tailwind CSS inside Chrome's native SidePanel API, giving users a side-by-side workspace while browsing LinkedIn.

### 3. Local-First Offline Storage
All saved items and annotations are stored locally in `IndexedDB`, guaranteeing sub-millisecond search performance even with thousands of saved posts.
