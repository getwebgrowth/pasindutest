## Executive Summary

**Polybiuos** is an AI-powered developer environment designed to accelerate code writing, refactoring, and media asset creation. Featuring a cyberpunk terminal interface with command execution history, syntax highlighting, and live code preview panels, Polybiuos turns developer prompts into production-ready React components and utility scripts.

- **Live URL**: [eigencode.vercel.app](https://eigencode.vercel.app/)
- **GitHub Repository**: [github.com/pasindupiumal03/Polybiuos_Project](https://github.com/pasindupiumal03/Polybiuos_Project)

---

## Technical Features & Stack

### 1. Cyberpunk Terminal & Code Editor
Built with Next.js 15, Radix UI, and Framer Motion, offering instant keyboard navigation, command palette (`Command+K`), and live syntax highlighting using Shiki.

### 2. Multi-Model AI Pipeline
Integrates with OpenAI API for real-time code refactoring, AST linting, automated unit test generation, and image asset generation.
