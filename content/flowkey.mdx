## Executive Summary

**FlowKey** is a modern browser extension and workspace dashboard designed to upgrade bookmark management with customizable grid layouts, quick search filters, and decentralized Web3 wallet authentication via the Solana Phantom Wallet SDK.

- **Chrome Web Store**: [Chrome Web Store Listing](https://chromewebstore.google.com/detail/flowkey-bookmark-layout-m/lpgjlhajnhhdbaleigdkeloeeniedpnj)
- **GitHub Repository**: [github.com/pasindupiumal03/FlowKey-Chrome-Extension](https://github.com/pasindupiumal03/FlowKey-Chrome-Extension)
- **Web Dashboard**: [flowkey-two.vercel.app](https://flowkey-two.vercel.app/)

## Engineering Architecture & System Design

```
┌─────────────────────────────────────────────────────────────┐
│                    FlowKey Browser App (MV3)                │
│                                                             │
│  ┌─────────────────────────────┐   ┌─────────────────────┐  │
│  │ React 18 Workspace Grid UI  │   │ Phantom Wallet SDK  │  │
│  │ (Drag-and-Drop Layout)      │──►│ (Ed25519 Auth Sign) │  │
│  └──────────────┬──────────────┘   └──────────▲──────────┘  │
│                 │ Encrypted Layout Data       │ Verified Wallet│
│                 ▼                             │ Identity     │
│  ┌────────────────────────────────────────────┴──────────┐  │
│  │ Chrome Storage Sync & Local-First Cache Engine        │  │
│  └──────────────────────────────┬────────────────────────┘  │
└─────────────────────────────────┼───────────────────────────┘
                                  ▼
                     Decentralized Arweave Sync
```

### 1. Solana Phantom Ed25519 Signature Authentication
Instead of traditional OAuth passwords, FlowKey authenticates users by requesting a cryptographic message signature via `@solana/web3.js` and Phantom wallet.

### 2. Sub-50ms Fuzzy Search Indexer
Stores bookmark metadata locally using `chrome.storage.local`, executing instant fuzzy searches across thousands of saved links using a client-side Trie index.
