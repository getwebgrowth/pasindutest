## Executive Summary

**FlowKey** is a modern browser extension and workspace dashboard designed to upgrade bookmark management with customizable grid layouts, quick search filters, and decentralized Web3 wallet authentication via the Solana Phantom Wallet SDK.

- **Status**: Live on the [Chrome Web Store](https://chromewebstore.google.com/detail/flowkey-bookmark-layout-m/lpgjlhajnhhdbaleigdkeloeeniedpnj)
- **Source Code**: [github.com/pasindupiumal03/FlowKey-Chrome-Extension](https://github.com/pasindupiumal03/FlowKey-Chrome-Extension)
- **Web App**: [flowkey-two.vercel.app](https://flowkey-two.vercel.app/)

---

## Key Features

1. **Custom Grid & Folder Layouts**: Drag-and-drop bookmark organization with customizable color palettes, icons, and tags.
2. **Web3 Wallet Sync**: Connect with Phantom wallet to store encrypted workspace configurations on decentralized storage.
3. **Sub-50ms Quick Search**: Instant keyboard shortcut overlay to fuzzy-search across thousands of saved links.
4. **Local-First Privacy**: Works 100% offline using `chrome.storage.local` with zero tracking.

---

## Technical Stack

- **Extension Framework**: Manifest V3, Webpack 5, React 18, Tailwind CSS.
- **Web3**: Solana Web3.js, Phantom Wallet SDK.
