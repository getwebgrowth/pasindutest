## Executive Summary

**Amazon Schedule Monitor** is a specialized background monitoring Chrome extension designed for flexible workforce employees and warehouse staff. It continuously monitors shift release schedules, triggering instant audio chimes and native OS push notifications the second a preferred work block becomes available.

- **GitHub Repository**: [github.com/pasindupiumal03/Amazon-Schedule-Monitor-Extension](https://github.com/pasindupiumal03/Amazon-Schedule-Monitor-Extension)
- **Key Features**: Background alarms polling, cookie session preservation, customizable criteria filters, and instant notification sound dispatch.

## Engineering Architecture & System Design

```
┌─────────────────────────────────────────────────────────────┐
│                   Chrome Extension (MV3)                    │
│                                                             │
│  ┌─────────────────────────────┐   ┌─────────────────────┐  │
│  │ Background Service Worker   │   │ Chrome Alarms Engine│  │
│  │ (Session Cookie Keeper)     │──►│ (Periodic Poll loop)│  │
│  └──────────────┬──────────────┘   └──────────▲──────────┘  │
│                 │ Intercept Endpoint          │ Trigger Alert│
│                 ▼                             │ Broadcast    │
│  ┌────────────────────────────────────────────┴──────────┐  │
│  │ DOM Mutation Observer & Notification Dispatcher       │  │
│  │ • Native Audio Beep Synthesizer                       │  │
│  │ • Push Notification API Bridge                        │  │
│  └──────────────────────────────┬────────────────────────┘  │
└─────────────────────────────────┼───────────────────────────┘
                                  ▼
                   Amazon Shift Schedule Endpoint
```

### 1. Persistent Background Alarms Engine
Utilizes `chrome.alarms` and service worker keepalives to poll shift endpoints at configurable intervals without triggering tab focus or high memory overhead.

### 2. Cookie Session Repair & Heartbeat
Detects auth redirection loops and automatically refreshes portal session tokens in background tabs, ensuring non-stop monitoring for up to 72 hours.
