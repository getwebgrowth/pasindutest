## Core Technical Innovations & Solved Engineering Hurdles

### 1. Innovation 1
**Global Keyboard Shortcut Modal**: Built an instant Command/Ctrl+Shift+K spotlight modal rendered in an isolated Shadow DOM root across all web domains.

### 2. Innovation 2
**Modular Prompt Template Engine**: Developed a customizable template library supporting dynamic variables (e.g. `{selected_text}`, `{page_title}`, `{tone}`) for instant prompt generation.

### 3. Innovation 3
**Universal Text Replacement Pipeline**: Engineered a DOM cursor position resolver that detects active input elements (textarea, contenteditable, code mirrors) and replaces selected text with AI completions.

### 4. Innovation 4
**Streaming LLM API Gateway**: Connected to OpenAI API endpoints with dynamic temperature and max-token configurations.
