## Executive Summary

**Positional AI** is a content verification browser extension built for editors, educators, publishers, and recruiters. The extension analyzes selected text or active article bodies, evaluating perplexity and burstiness metrics to calculate a precise Human vs. Artificial Intelligence probability score (e.g. "20% Human, 80% Artificial Intelligence").

- **Target Audience**: Content managers, academic checkers, SEO teams, and hiring managers.
- **Capabilities**: 1-click DOM text selection analysis, visual progress meter popup, and tone breakdown.

## Engineering Architecture & System Design

```
┌─────────────────────────────────────────────────────────────┐
│                    Browser Active Tab (MV3)                 │
│                                                             │
│  ┌─────────────────────────────┐   ┌─────────────────────┐  │
│  │ DOM Selection Text Parser   │   │ Probability Popup   │  │
│  │ (Perplexity & Burstiness)   │──►│ (Human vs AI Meter) │  │
│  └──────────────┬──────────────┘   └──────────▲──────────┘  │
│                 │ Cleaned Text Tokens         │ Verdict & % │
│                 ▼                             │ Breakdown   │
│  ┌────────────────────────────────────────────┴──────────┐  │
│  │ Machine Learning Classification Model Engine          │  │
│  └──────────────────────────────┬────────────────────────┘  │
└─────────────────────────────────┼───────────────────────────┘
                                  ▼
                   OpenAI Token Predictability API
```

### 1. Selection & Article Body Parser
Extracts article text dynamically using `window.getSelection()` or article container heuristic parsers, filtering out navigation headers and sidebar boilerplate.

### 2. Machine Learning Probability Model
Pipes cleaned text payloads to classification models that measure sentence length variance and token predictability to render instant percentage breakdown cards.
