## Executive Summary

**FullGrab** is a modern browser extension that captures pixel-perfect full-page web screenshots, selected DOM regions, and visible viewports. Unlike server-side screenshot APIs that fail on paywalled or authenticated pages, FullGrab runs 100% on the client side using a smart auto-scrolling engine and HTML5 canvas stitching.

- **Status**: Live on the [Chrome Web Store](https://chromewebstore.google.com/detail/fullgrab-screenshot-full/jfpjeaefbhfogcponhjgpghahalcbplf)
- **Source Code**: [github.com/pasindupiumal03/FullGrab-Extension](https://github.com/pasindupiumal03/FullGrab-Extension)

---

## Key Features

1. **Smart Auto-Scrolling & Canvas Stitching**: Automatically scrolls through infinite-scroll pages, capturing sequential viewports and stitching them into a unified high-resolution PNG/PDF.
2. **Fixed Element Suppression**: Automatically detects sticky headers and floating chat widgets, preventing duplicate repeating elements in full-page captures.
3. **Local Privacy-First Processing**: Image stitching is performed entirely within the client's browser memory, ensuring zero data leakage for private documents.
4. **Stripe Cloud Sharing**: Users can subscribe to premium cloud storage plans to generate instant, password-protected shareable links.

---

## Technical Stack

- **Extension Framework**: Manifest V3, `chrome.tabs.captureVisibleTab`, `chrome.offscreen`.
- **Image Processing**: HTML5 Canvas API, OffscreenCanvas, Binary Blob serialization.
- **Frontend & Monetization**: React.js, Tailwind CSS, Stripe Billing API.
