## Executive Summary

**Zillow Real Estate Scraper** is an automated property intelligence pipeline built for real estate agents, wholesalers, and market investors. The tool continuously extracts property listings matching target parameters (price, price-per-sqft, beds/baths, lot size, year built, listing type) and writes structured listing records into Google Sheets in real-time.

- **Extraction Targets**: Listing address, price, zestimate, price per sqft, agent contact info, listing age, and price reduction history.
- **Delivery Format**: Automated Google Sheets rows & Discord webhook notifications.
- **Anti-Bot Resilience**: Bypasses anti-scraping protections via header randomization and headless browser session rotation.

### 1. Robust Anti-Detection Layer
Utilizes Puppeteer-Stealth with dynamic user-agent pools, canvas fingerprint spoofing, and randomized request delays to bypass cloud security gateways without IP bans.

### 2. Google Sheets API v4 Integration
Constructs batch update requests to append formatted property rows directly to target client spreadsheets, enabling real-time collaboration across real estate acquisition teams.

### 3. Automated Listing Alerts
Triggers instant Discord and SMS alerts when high-yield properties matching buy box parameters hit the market.
