## Core Technical Innovations & Solved Engineering Hurdles

### 1. Multi-Account Session Switching & Token Persistence
Architected a secure session switching manager in `chrome.storage.sync` allowing agency staff to toggle between client Klaviyo workspaces with preserved credentials.

### 2. Client-Side Canvas Image Compression Pipeline
Built an in-browser Web Worker image processing pipeline using HTML5 `<canvas>` that automatically resizes and compresses high-resolution banner graphics to Klaviyo-recommended email specs (under 1MB) before upload.

### 3. Bulk Campaign Date & Time Matrix Scheduler
Engineered an automated calendar scheduling injector that programs launch dates, segment exclusions, and UTM parameters across multiple draft emails in parallel.

### 4. DOM Mutation Observer for Dynamic Klaviyo SPA UI
Attached non-intrusive action buttons to the Klaviyo dashboard using throttled DOM observers, ensuring tools remain active across client-side route transitions.
