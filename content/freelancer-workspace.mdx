## Executive Summary

**Freelancer Workspace** is a client management, time tracking, and invoicing SPA designed specifically for independent freelancers and contractors. Built on Google Apps Script and Google Sheets, it eliminates monthly SaaS subscription fees while giving users an app-like dashboard to manage hourly contracts, track unbilled time, and generate professional PDF invoices.

- **Data Privacy**: 100% self-hosted inside user Google Drive with zero external server dependencies.
- **Key Modules**: Time tracker timer, invoice generator, client CRM, expense tracker, and earnings dashboard.

---

## Technical Features & Solutions

### 1. Zero-Latency Local Time Tracker
Uses client-side JavaScript timers to record active work sessions, storing state in browser memory before batch-writing completed sessions to Google Sheets via `google.script.run`.

### 2. PDF Invoice Render & Delivery Pipeline
Converts selected project hours into branded HTML invoice layouts, invoking Apps Script `DriveApp` to compile PDFs and send automated email notifications to clients.
