## Core Technical Innovations & Solved Engineering Hurdles

### 1. Persistent Draggable React HUD in Shadow DOM
Injected a sleek floating developer widget using Custom Shadow DOM boundaries with coordinate persistence in `chrome.storage.local` to prevent interfering with host page layouts.

### 2. Resilient Alarm-Driven Timekeeping Engine
Utilized `chrome.alarms` and persistent timestamps to maintain accurate timekeeping even when Chromium terminates the background service worker during periods of inactivity.

### 3. Automated Atlassian Jira Cloud REST API v3 Integration
Automated ticket transitions (To Do -> In Progress -> Code Review -> Done) and formatted precise Jira ISO-8601 worklog payloads with custom issue key parsing.

### 4. Offline Queue with Automatic Reconnection Sync
Engineered an offline cache that stores worklogs locally during network drops and syncs them automatically to Jira once internet connectivity is restored.
